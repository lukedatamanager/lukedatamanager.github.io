# Luke Data Manager

## About

Welcome to the personal website of **Luke Marsden**, a scientific data manager at the Norwegian Meteorological Institute and the University Centre in Svalbard.

This site explores the practical side of scientific data management—organizing data effectively, building workflows, improving access to environmental datasets, and bridging the gap between producing scientific data and creating real-world impact.
